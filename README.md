### Tesi Triennale - 2024

## 🏥 Descrizione
**MED (Medical Environment Database)** è una soluzione software alternativa volta alla gestione automatica dei dati che accompagnano il paziente dalla sua accettazione alla dimissione.

Lo scopo del progetto è implementare una soluzione software per la **raccolta, scrittura e consultazione** dei dati relativi al paziente, contribuendo inoltre a raccogliere una serie di **rilevazioni sui parametri vitali**, al fine di migliorare l'efficienza ospedaliera e il mantenimento dei dati.

L'interazione con il sistema avviene attraverso un'**interfaccia grafica (GUI)**.

## 🎯 Obiettivi

- **Gestire** automaticamente i dati del paziente durante il suo percorso ospedaliero, dall'accettazione alla dimissione.
- **Raccogliere** e mantenere i dati relativi al paziente.
- **Registrare** una serie di rilevazioni riguardanti i parametri vitali.
- **Migliorare** l'efficienza nella gestione dei dati ospedalieri.
- **Fornire** un'interfaccia grafica (GUI) per l'interazione con il software.

## 🚀 Installazione e avvio

Per usufruire del software, è necessario procedere al download del file `.zip` dalla pagina principale di GitHub. È possibile farlo cliccando sull'opzione **"Code"** e successivamente selezionando **"Download ZIP"**.

Una volta completato il download, estrarre il file ZIP ottenuto in una directory a scelta all'interno del computer.

Successivamente, navigare attraverso le cartelle fino a raggiungere il seguente percorso:

```text
MED-main/
└── MED-main/
    └── code/
        └── progetto_logico/
```

A questo punto, eseguire il file `.jar` denominato **`MED.jar`**. In alternativa, è possibile eseguirlo direttamente dal desktop creando un collegamento al medesimo file `.jar`.

### 💻 Avvio tramite Eclipse IDE

In alternativa, è possibile importare il software nell'ambiente di sviluppo **Eclipse IDE**.

Assicurarsi che siano presenti **tutti e quattro i progetti** e avviare il software utilizzando la classe **`Main`**, presente nel progetto **`progetto_logico`**, all'interno del package **`eseguibile`**.
